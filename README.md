# HorseScope

Breed the fastest horse without guessing. HorseScope shows the stats
of the horse you are riding — or the one under your crosshair — right
above the hotbar: speed in m/s, jump height in blocks, and current/max
health. Stats refresh every 10 ticks and clear automatically when no
horse is targeted.

## Features

- **Live horse stat HUD** — white text above the hotbar like
  "Speed: 12.4 m/s", "Jump: 4.2 blocks", "Health: 24/30"
- **Riding or looking** — inspects the horse you are mounted on, or
  the horse under your crosshair when on foot
- **Auto-refresh** — stats update every 10 ticks; the panel clears
  when no horse is targeted
- **Zero config** — drop it in and play

## Install

1. Install [Fabric Loader](https://fabricmc.net/use/) 0.19.2+ for
   Minecraft 26.2
2. Install [Fabric API](https://modrinth.com/mod/fabric-api) for
   Minecraft 26.2
3. Drop `horsescope-1.0.0.jar` into your `mods` folder
4. Launch and play — no config needed

## Notes

- Client-side only. Works on any server (including vanilla).
- No mixins, no networking, nothing saved to disk.
